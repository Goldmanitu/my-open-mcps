# Telegram Alerts для Codex

Telegram Alerts добавляет в Codex один безопасный инструмент для отправки
уведомлений в Telegram:

```text
send_alert(message, event_id)
```

Он отправляет сообщение только в один заранее настроенный чат. Codex не может
выбрать другого получателя, потому что chat ID не передаётся модели и хранится
локально на вашем компьютере.

Эта инструкция рассчитана на macOS и на человека, который впервые настраивает
бота. Выполняйте шаги по порядку.

## Что потребуется

1. Mac с установленным приложением Codex.
2. Приложение Telegram на телефоне или компьютере.
3. Доступ к интернету.
4. Python 3.11 или новее. Проверим его в шаге 3.

Не отправляйте токен бота никому: не вставляйте его в чат с AI, GitHub, заметки,
скриншоты или письма.

## 1. Создайте Telegram-бота

1. Откройте Telegram.
2. В поиске найдите **@BotFather** и откройте чат с ним. Это официальный бот
   Telegram с синей галочкой.
3. Отправьте команду `/newbot`.
4. Введите отображаемое имя, например `Мои уведомления`.
5. Введите username. Он обязательно должен оканчиваться на `bot`, например
   `my_alerts_example_bot`.
6. BotFather покажет строку вида `123456:ABC...`. Это токен вашего бота.
   Скопируйте его, но никуда не публикуйте.
7. В поиске Telegram найдите созданного бота, откройте чат и нажмите **Start**
   или отправьте `/start`. Без этого бот не сможет написать вам первым.

## 2. Подготовьте Python

1. На Mac нажмите `⌘ Space`, напишите `Terminal` и нажмите Enter.
2. В открывшемся окне выполните:

   ```zsh
   python3 --version
   ```

3. Если версия начинается с `Python 3.11`, `3.12`, `3.13` или новее, переходите
   к следующей команде. Если команда не найдена или версия ниже 3.11, установите
   актуальный Python с [официального сайта Python](https://www.python.org/downloads/macos/),
   закройте Terminal, откройте его снова и повторите проверку.
4. Скопируйте в Terminal команды ниже и нажимайте Enter после каждой:

   ```zsh
   mkdir -p "$HOME/.local/share/telegram-alert-mcp"
   python3 -m venv "$HOME/.local/share/telegram-alert-mcp/venv"
   "$HOME/.local/share/telegram-alert-mcp/venv/bin/python" -m pip install --upgrade pip
   "$HOME/.local/share/telegram-alert-mcp/venv/bin/pip" install 'mcp>=1.27,<2'
   ```

Дождитесь строки без ошибок. Это создаёт отдельное окружение только для этого
плагина; системный Python не меняется.

## 3. Сохраните токен в Keychain

Keychain — защищённое хранилище паролей macOS. В том же окне Terminal выполните
первую команду:

```zsh
security add-generic-password -U -s telegram-alert-mcp -a bot-token -w
```

Terminal попросит пароль. Вставьте токен, который показал BotFather, и нажмите
Enter. Символы при вводе могут не отображаться — это нормально.

Не выполняйте команду `security find-generic-password ... -w` при посторонних:
она выводит сохранённый секрет на экран.

## 4. Добавьте плагин в Codex

В Terminal выполните:

```zsh
codex plugin marketplace add Goldmanitu/my-open-mcps --ref main
codex plugin add telegram-alert-mcp@goldmanitu-my-open-mcps
```

Если Codex напишет, что marketplace или плагин уже добавлен, это не ошибка.
Полностью закройте приложение Codex и откройте его снова. Затем создайте новую
задачу: новые задачи получают установленный MCP-инструмент и skill.

## 5. Выберите чат через ChatGPT

В Telegram откройте созданного бота и нажмите **Start** или отправьте ему
`/start`. Это нужно сделать только один раз для каждого нового личного чата.

В новой задаче Codex вставьте этот текст:

```text
Используй Telegram Alerts. Проверь подключение к моему боту и найди чаты,
которые недавно написали ему. Покажи только Chat ID и тип чата, не показывай
текст сообщений. После того как я выберу один Chat ID, спроси подтверждение,
сохрани его как единственный чат для алертов и отправь тест.
```

Codex сначала покажет что-то вроде:

```text
Chat ID: 165853447
Тип: личный чат
```

Подтвердите именно тот чат, в который должны приходить уведомления. Codex
сохранит выбранный ID в защищённом Keychain macOS. Токен, сообщения и их текст
в этот момент не показываются.

Если один бот используется в нескольких личных чатах, группах или каналах,
каждый из них будет иметь свой Chat ID. Для одного экземпляра плагина выбирают
один фиксированный чат. Для другого получателя повторите настройку и явно
подтвердите замену.

## 6. Отправьте первое тестовое уведомление

В новой задаче Codex вставьте этот текст:

```text
Используй Telegram Alerts. Отправь тестовое уведомление в уже выбранный чат.
```

Codex покажет действие `send_setup_test` и попросит подтвердить отправку.
Проверьте текст и подтвердите. В чате с вашим ботом появится сообщение.
Повторный запуск не создаст дубликат теста.

## Использование в автоматизации

Плагин отправляет уведомления, но сам не читает почту и не запускает расписание.
Его можно использовать после любого условия: письма, задачи, изменения статуса
или результата проверки.

Для уведомлений о новых письмах используйте неизменяемый ID письма в `event_id`:

```text
gmail:<Message-ID>:important-v1
yandex:<folder>:<UID>:important-v1
```

Не используйте текущую дату, случайный UUID или номер запуска расписания: при
каждом цикле они меняются, поэтому одно и то же уведомление может прийти повторно.
Готовый шаблон почтового сценария находится в [WORKFLOW.md](WORKFLOW.md).

## Если что-то не работает

| Что вы видите | Что сделать |
| --- | --- |
| `python3: command not found` или версия ниже 3.11 | Установите Python по ссылке из шага 2, затем заново откройте Terminal. |
| Ошибка про `MCP Python SDK` | Повторите все четыре команды из шага 2. |
| Плагин не виден в Codex | Выполните команды из шага 4, полностью перезапустите Codex и создайте новую задачу. |
| Плагин не находит чат | Откройте чат с созданным ботом, нажмите **Start**, отправьте `/start` и повторите поиск чатов в новой задаче Codex. |
| Подтверждение прошло, но сообщения нет | Проверьте, что вы выбрали нужный Chat ID, а бот добавлен в нужную группу или канал с правом отправки сообщений. |
| `duplicate_suppressed` | Это защита от дублей: тест уже был отправлен в выбранный чат. |
| Вы получили новый токен BotFather | Повторите команду из шага 3 и вставьте новый токен. Старый будет заменён. |

## Безопасность и приватность

- Токен и выбранный chat ID хранятся на вашем Mac в Keychain, а не в GitHub.
- Поиск чатов возвращает только числовые IDs и типы чатов, без текста сообщений.
- После явного подтверждения получатель фиксируется числовым chat ID.
- Текст сообщения отправляется в Telegram; не включайте в него пароли, платёжные,
  медицинские или иные конфиденциальные данные.
- Сообщения отправляются как обычный текст: HTML и Markdown из внешних данных не
  исполняются, предпросмотр ссылок отключён.
- Для одинакового `event_id` плагин предотвращает повторную отправку.
